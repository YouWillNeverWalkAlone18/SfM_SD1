# 実験に関するご説明
      
実験に興味を持っていただきありがとうございます。

今回、錯視や錯覚を研究する知覚心理学という分野の実験を実施しています。

実験は全体で80試行を行います。

各試行では、画面中央に複数の小さな四角形がランダムに配置され、2秒間、左右方向に動きます。

画面を見て、円筒が回転しているように見えた場合は、見えた回転方向をボタンで選択します。

時計回りに見えた場合は「時計回り」、反時計回りに見えた場合は「反時計回り」のボタンを押します。

回転方向が途中で変わったり、どちらの回転も見えたり、はっきりとわかりにくい場合は、

より強く感じた回転方向を回答します。

# 실험 설명

인간이 감각정보를 해석하는 과정을 해명하는 지각심리학이라는 분야의 실험을 실시합니다.

이번 실험의 목적은, 불확실한 운동 방향을 판단할 때 과거 정보가 현재의 판단에 미치는 영향을 연구하는 것입니다.

실험은 [화면에 자극 제시] - [지시에 따라 응답]까지가 1시행이며, 총 80시행 실시합니다.

각 시행에서는 화면 중앙에 복수의 작은 사각형이 배치되어, 2초간 좌우로 왕복합니다. (이를 '자극'이라 함) 

해당 장면을 관찰하면 원통이 회전하는 착시가 일어나는데, 

이 때 관찰된 회전의 방향을 버튼을 눌러 응답합니다. 

시계 방향으로 보였다면 [시계 방향], 반시계 방향으로 보였다면 [반시계 방향]을 클릭하시면 됩니다. 

관찰 도중에 회전 방향이 바뀌었거나, 두 방향이 동시에 관찰되는 등 어느 방향인지 확신이 서지 않는다면, 

보다 강하게 느껴진 회전방향을 응답해주십시오.
